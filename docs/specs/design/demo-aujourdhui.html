Ce que montre la planche

Fond magnésie, encre, une seule couleur d'action : la résine. Les couleurs de prises n'apparaissent que dans les pastilles, à côté de leur nom.

La séance du jour est une fiche vissée : étiquette en chasse fixe, repères carrés, durées alignées.

Les boutons ont un relief dur : ils descendent sous le doigt. Tous font au moins 56 px de haut.

La semaine montre ce qui est fait (fond résine doux), aujourd'hui (cadre résine), ce qui est prévu (carré) et les jours de repos (tiret, bord pointillé). Chaque jour a aussi son nom complet pour les lecteurs d'écran.
